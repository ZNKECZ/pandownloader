============================================================
  网盘下载器 APK 云编译指南（大哥专用，5 分钟搞定）
============================================================

【为什么走云编译】
本机没有 Android 打包环境（Java/SDK/NDK 合计 6GB+），
GitHub Actions 免费提供 Linux 编译机，推代码上去自动出 APK。

============================================================
第一步：注册/登录 GitHub（有账号直接登录）
============================================================
打开 https://github.com → 右上角 Sign up 注册（邮箱即可，1分钟）

============================================================
第二步：建仓库
============================================================
1. 登录后点右上角【+】→【New repository】
2. Repository name 填：pandownloader
3. 选 Public（私有也行，Actions 一样能跑）
4. 勾【Add a README file】→ 点【Create repository】

============================================================
第三步：上传代码
============================================================
方式一（网页传，最简单）：
1. 把 android_app.zip 解压到电脑任意位置
2. 在刚建的仓库页面点【uploading an existing file】
3. 把解压出来的全部文件/文件夹拖进去（含 .github 文件夹！）
4. 页面底部点【Commit changes】

方式二（装了 git 的话）：
  git clone https://github.com/你的用户名/pandownloader.git
  把解压的文件全部复制进去（覆盖 README）
  git add . && git commit -m "v2.2 android" && git push

============================================================
第四步：等编译（40-60 分钟）
============================================================
1. 上传后点仓库顶部【Actions】标签
2. 看到一个黄色圆点在转 = 正在编译（首次要下载 SDK/NDK，慢属正常）
3. 变绿色对勾 = 编译成功；红色叉 = 失败（点进去把日志发我）

============================================================
第五步：下载 APK 装手机
============================================================
1. 绿色对勾那次运行点进去，拉到底部【Artifacts】
2. 下载 pandownloader-apk.zip，解压出 .apk 发到手机
3. 手机点 APK 安装（提示"未知来源"选允许）

============================================================
手机上首次使用
============================================================
1. 打开 APP，首次会跳系统设置要"所有文件访问"权限
   （为了把文件存到 下载/网盘下载 目录），点允许后按返回键回来
2. 粘贴夸克/UC 分享链接 → 点解析
3. 夸克会自动打开登录页：用 短信验证码 或 夸克APP扫码 登录
   登录成功自动跳回主界面并继续解析
4. 勾选文件 → 点下载（默认 32 线程，文件在 下载/网盘下载 里）

============================================================
注意事项
============================================================
- .github 文件夹必须传（里面有自动编译配置），网页上传时
  注意别漏（它名字以点开头，解压后可能被系统隐藏：
  文件夹选项 → 查看 → 显示隐藏文件）
- 编译失败把 Actions 里的红色日志页面发我，我远程修
- 手机 Android 8 以下老机器跑不了（最低 Android 7）
