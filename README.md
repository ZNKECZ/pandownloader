# 网盘下载器 Android 版

UC + 夸克网盘分享链接 → 解析 → 直链提取 → 多线程下载到手机。

## 功能

- 粘贴分享链接自动识别网盘（UC / 夸克）
- 夸克需要登录时自动打开登录页，登录成功自动提取 Cookie 并返回继续
- 多线程分块下载（最高 128 线程），滑动窗口实时测速
- 下载文件保存到 `Download/网盘下载/`

## 云编译 APK（GitHub Actions）

推送本目录到 GitHub 仓库后，Actions 自动用 Buildozer 编译，完成后在
Actions 运行页的 Artifacts 里下载 `pandownloader-apk`。

首次编译约 40-60 分钟（下载 SDK/NDK 并编译 Python）。

## 首次使用

1. 安装 APK 后打开，首次会跳系统设置请求「所有文件访问」权限（用于保存到公共下载目录），允许后返回
2. 粘贴分享链接 → 解析 → 勾选文件 → 下载
3. 夸克链接会自动打开登录页，登录（短信验证码/夸克APP扫码）后自动返回
